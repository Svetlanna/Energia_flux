extraction / edf py
    extraction (API gouvernement).

    Telecharge les donnees RTE eCO2mix (consommation, production par filiere,
    taux de CO2...) depuis l'API ODRE / data.gouv.fr et les sauvegarde
    localement en JSON lisible

ingestion py

    ingestion et validation.

    1. Validation du format   : verifie que le JSON brut a la structure attendue
                                 et que les champs obligatoires sont presents.
    2. Conversion unifiee     : ne garde que les colonnes utiles au modele
                                 (date_heure, consommation, nucleaire, eolien,
                                 solaire, hydraulique, taux_co2).
    3. Sauvegarde intermediaire : ecrit un CSV propre, pret pour l'ETL

INIT py
 c'est pour  dire à Python "ce dossier est un package importable". Sans __init__.py dans extraction/ et ingestion/,
  la ligne from extraction.EDF import ... dans index.py échouerait (ModuleNotFoundError)

etl.py va lire ton CSV et remplir MySQL


connecter_db()  ouvre la connexion à MySQL, en lisant host/user/password/nom de la base depuis .env
charger_lignes_csv() relit ton CSV unifié
inserer_dans_mysql() insère chaque ligne dans la table consommation. INSERT IGNORE veut dire : si une ligne avec la même date_heure
existe déjà, MySQL la saute au lieu de planter — donc tu peux relancer le script plusieurs fois sans créer de doublons

sauvegarder_datalake()  fait une copie du CSV avec la date/heure dans le nom, dans data/datalake/. C'est ton historique brut,
séparé de MySQL
